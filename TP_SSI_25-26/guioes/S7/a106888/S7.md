## Configuração do Ambiente

Recomenda-se usar uma VM para não estragar a máquina local.
Sugestão com multipass:

```bash
multipass launch --name Nome
multipass shell Nome
```

É necessário ter Python 3 e as bibliotecas `cryptography` e `hashpumpy` instaladas:

```bash
sudo apt install python3 python3-pip
pip3 install cryptography hashpumpy
```

---

## Execução

Todos os scripts estão na raiz da pasta `a106888/`.

```bash
# MAC com SHA256 (prefix-MAC)
python3 mac_sha256.py setup chave.key
python3 mac_sha256.py mac mensagem.txt chave.key
python3 mac_sha256.py ver mensagem.txt chave.key

# Ataque de extensão de comprimento
python3 mac_sha256_attack.py mensagem.txt "&admin=true"
python3 mac_sha256.py ver mensagem.txt.ext chave.key

# AES-CTR + HMAC-SHA256 (encrypt-then-MAC)
python3 pbenc_aes_ctr_hmac.py enc ficheiro.txt
python3 pbenc_aes_ctr_hmac.py dec ficheiro.txt.enc

# AES-GCM (cifra autenticada)
python3 pbenc_aes_gcm.py enc ficheiro.txt
python3 pbenc_aes_gcm.py dec ficheiro.txt.enc
```
