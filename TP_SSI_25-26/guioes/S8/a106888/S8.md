## Configuração do Ambiente

Recomenda-se usar uma VM para não estragar a máquina local.
Sugestão com multipass:

```bash
multipass launch --name Nome
multipass shell Nome
```

É necessário ter Python 3, a biblioteca `cryptography` e o `openssl` instalados:

```bash
sudo apt install python3 python3-pip openssl
pip3 install cryptography --break-system-packages
```

## Execução

Todos os scripts estão na raiz da pasta `a106888/`.

```bash
# Acordo de chaves Diffie-Hellman (imprime K em ambos os processos)
python3 dh.py

# DH + mensagem cifrada com AES-GCM (usando HKDF para derivar a chave)
python3 dh_aes_gcm.py
```

Para o protocolo Station-to-Station é necessário gerar primeiro os certificados:

```bash
openssl genrsa -out CA.key 2048
openssl genrsa -out Alice.key 2048
openssl genrsa -out Bob.key 2048

openssl req -x509 -new -nodes -key CA.key -sha256 -days 365 -out CA.crt -subj "/CN=CA"

openssl req -new -key Alice.key -out Alice.csr -subj "/CN=Alice"
openssl x509 -req -in Alice.csr -CA CA.crt -CAkey CA.key -CAcreateserial -out Alice.crt -days 365 -sha256

openssl req -new -key Bob.key -out Bob.csr -subj "/CN=Bob"
openssl x509 -req -in Bob.csr -CA CA.crt -CAkey CA.key -CAcreateserial -out Bob.crt -days 365 -sha256

# Station-to-Station (DH autenticado com certificados RSA + AES-GCM)
python3 sts_aes_gcm.py
```
