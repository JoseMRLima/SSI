## Configuração do Ambiente

Recomenda-se usar uma VM para não estragar a máquina local.
Sugestão com multipass:

```bash
multipass launch --name Nome
multipass shell Nome
```

É necessário ter Python 3 e a biblioteca `cryptography` instalados:

```bash
sudo apt install python3 python3-pip
pip3 install cryptography
```

---

## Execução

Todos os scripts estão na raiz da pasta `a106888/`.

```bash
# ChaCha20 — cifrar e decifrar ficheiro
python3 cfich_chacha20.py setup chave.key
python3 cfich_chacha20.py enc ficheiro.txt chave.key
python3 cfich_chacha20.py dec ficheiro.txt.enc chave.key

# Ataque de integridade ao ChaCha20
python3 chacha20_int_attck.py ficheiro.txt.enc 0 "texto" "TEXTO"

# AES-CBC — cifrar e decifrar ficheiro
python3 cfich_aes_cbc.py setup chave_cbc.key
python3 cfich_aes_cbc.py enc ficheiro.txt chave_cbc.key
python3 cfich_aes_cbc.py dec ficheiro.txt.enc chave_cbc.key

# AES-CTR — cifrar e decifrar ficheiro
python3 cfich_aes_ctr.py setup chave_ctr.key
python3 cfich_aes_ctr.py enc ficheiro.txt chave_ctr.key
python3 cfich_aes_ctr.py dec ficheiro.txt.enc chave_ctr.key

# ChaCha20 com cifração baseada em password
python3 pbenc_chacha20.py enc ficheiro.txt
python3 pbenc_chacha20.py dec ficheiro.txt.enc
```
