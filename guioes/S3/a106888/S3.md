## Configuração do Ambiente

Recomenda-se usar uma VM para não estragar a máquina local.  
Sugestão com multipass:

```bash
multipass launch --name Nome
multipass shell Nome
```

Depois de estar na VM, dar permissões de execução aos scripts:

```bash
chmod +x sec1/sec1.sh sec2/sec2.sh sec3/sec3.sh sec4/sec4.sh sec5/sec5.sh
```

> A maioria dos comandos das secções 2 a 5 precisa de `sudo`.  
> A secção 4 precisa do pacote acl: `sudo apt install acl`

---

## Execução

Correr cada script dentro da sua pasta:

```bash
cd sec1 && bash sec1.sh
cd ../sec2 && sudo bash sec2.sh
# etc.
```
